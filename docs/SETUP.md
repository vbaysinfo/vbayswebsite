# Go-live setup guide

Allow about 45 minutes. You need a Google account, a Meta Business account (for Instagram/Facebook automation), and a hosting account (Vercel recommended).

---

## 1. Google Sheet + Apps Script API (created automatically in your Drive folder)

The spreadsheet is **created automatically** in this Google Drive folder:
**https://drive.google.com/drive/folders/1_eMSIYfdKgBis4sOaWs_yKBbAmH0-yRu**
(set in `apps-script/Setup.gs` → `DEFAULT_DRIVE_FOLDER_ID`, or override it with the `DRIVE_FOLDER_ID` Script Property.)

1. Sign in with the Google account that **owns (or can edit) that folder**, then open **script.google.com → New project**. Name it, for example, "VBays Interiors API".
2. Create these files and paste in the matching file from `apps-script/`:
   `Code.gs`, `Social.gs`, `Setup.gs`, `Schema.gs`.
3. **Project Settings (⚙)** → tick *Show "appsscript.json"* → paste `apps-script/appsscript.json` into it.
4. Choose the function **`setup`** → **Run** → approve the permissions. In the Drive folder it creates:

   ```
   📁 your folder
   ├── 📊 VBays Interiors — Website Data     ← all 12 tabs, headers, drop-downs, starter content
   ├── 📁 Lead Uploads (private)             ← customers' floor plans / reference images
   └── 📁 Excel Backups                      ← daily .xlsx copy of the sheet (latest 14 kept)
   ```

   The execution log prints the spreadsheet link. `setup` also generates an `API_SECRET`. Re-running it is safe: it reuses the same spreadsheet, adds any missing tabs or columns, and never deletes data.
   From then on, every website enquiry, WhatsApp/call click, social post and campaign metric is **written into that spreadsheet automatically**. Content you edit in the sheet updates the website.
5. Run **`setupTriggers`** once. It installs these triggers:
   - `processScheduledPosts`: every 15 minutes (social publishing)
   - `sendFollowUpDigest`: daily at 9 AM IST
   - `exportExcelBackup`: daily at 2 AM IST (Excel `.xlsx` backup into *Excel Backups*)
   - `recomputeCampaigns`: every 6 hours
   - `onSheetEdit`: refreshes the website after content edits
   - `onOpen`: adds the **Website** menu to the spreadsheet
6. **Keep the folder private.** Uploads and backups contain customer data. The script turns off link-sharing on its subfolders and files, but anyone you share the *parent* folder with directly can still see them.

7. **Project Settings → Script Properties**:

   | Property | Required | Value |
   |---|---|---|
   | `API_SECRET` | ✅ | Auto-generated by `setup`. Copy it for step 3 |
   | `NOTIFY_EMAIL` | recommended | Where new-lead alerts and the daily follow-up digest go |
   | `WEBSITE_URL` | recommended | `https://www.yourdomain.com` |
   | `REVALIDATE_SECRET` | recommended | A random string of 16+ characters. Also set it on the website |
   | `SPREADSHEET_ID`, `UPLOAD_FOLDER_ID` | auto | Set by `setup`. Don't change them |
   | `DRIVE_FOLDER_ID` | optional | Use a different Drive folder than the default |
   | `META_ACCESS_TOKEN`, `IG_USER_ID` | for Instagram | See step 2 |
   | `FB_PAGE_ID`, `FB_PAGE_TOKEN` | for Facebook | See step 2 |
   | `GRAPH_VERSION` | optional | Default `v23.0` |

8. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (every data request still needs `API_SECRET`; anonymous GETs return only public, active website content)
   - Copy the **Web app URL**.

> After you edit Apps Script code, use **Deploy → Manage deployments → Edit → New version**. Otherwise the URL keeps serving the old code.

The sheet gets a **Website** menu: *Refresh website now*, *Publish due social posts now*, *Recalculate campaign metrics*, *Send follow-up digest now*, *Save Excel (.xlsx) backup now*.

### Editing content
- **SETTINGS**: company info, phone, WhatsApp (digits with country code, e.g. `919876543210`), addresses, maps links, social links, CTA text, default city, service areas (comma-separated; each area gets SEO pages), staff names, hero images, and *Auto Publish*.
- **SERVICES**: SEO fields can use `{city}`. For list fields (Gallery Images, Benefits, Materials, Design Examples), put one item per line. For FAQs, write one per line as `Question :: Answer`.
- **Images**: use any public https URL. Google Drive share links work if the file is shared as "Anyone with the link".
- **TESTIMONIALS**: only rows with `Active = TRUE` appear, so add real, approved reviews only.
- Changes appear on the website within about 5 minutes, or immediately with *Website → Refresh website now* / *Admin → Website Content → Refresh*.

## 2. Instagram & Facebook (official Graph API)

1. The Instagram account must be a **Professional (Business/Creator)** account linked to a **Facebook Page**.
2. At developers.facebook.com, create an app (type *Business*). Add **Instagram Graph API** and **Facebook Login for Business**.
3. Generate a long-lived token with these permissions: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`.
4. Find the Instagram user ID: `GET /me/accounts` → the page → `?fields=instagram_business_account`.
5. Save `META_ACCESS_TOKEN`, `IG_USER_ID`, `FB_PAGE_ID` and `FB_PAGE_TOKEN` in Script Properties.

What gets auto-published:
- **Instagram**: Image, Carousel (2–10 images, one URL per line), Reel/Video, Story.
- **Facebook**: Photo, multi-photo, Video, text-only.
- **YouTube, LinkedIn, Pinterest, Facebook Reels/Stories**: marked **Ready to Publish** for manual posting. Paste the live URL into *Published URL* afterwards.

Media must be at public https URLs. Meta fetches them directly.

## 3. Website environment variables

Set these in your host (Vercel → Project → Settings → Environment Variables):

| Variable | Notes |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://www.yourdomain.com`, used for canonical URLs and the sitemap |
| `APPS_SCRIPT_URL` | Web app URL from step 1.8 (**server-only**) |
| `APPS_SCRIPT_SECRET` | The `API_SECRET` value (**server-only**) |
| `REVALIDATE_SECRET` | Same value as the Script Property |
| `ADMIN_USERS` | `owner:StrongPass123:admin,sales1:AnotherPass:staff`. Passwords must be 8+ characters. *staff* can manage leads only |
| `ADMIN_SESSION_SECRET` | A random string of 32+ characters (`openssl rand -base64 48`) |
| `GOOGLE_SHEET_URL` | Optional. Adds an "Open Google Sheet" button in the admin |
| `NEXT_PUBLIC_GA_ID` | GA4 Measurement ID `G-XXXXXXX` |
| `NEXT_PUBLIC_GSC_VERIFICATION` | Search Console HTML-tag verification code |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | Optional Cloudflare Turnstile CAPTCHA |

Deploy: `npm run build` must pass. On Vercel, import the repo and deploy.

## 4. Google Analytics 4, Search Console, Maps, Business Profile

- **GA4**: create a property, then set `NEXT_PUBLIC_GA_ID`. Under *Admin → Events*, mark `lead_form_submit`, `whatsapp_click` and `call_click` as **key events**. UTM parameters flow in automatically.
- **Search Console**: add the domain, choose the *HTML tag* method, and copy the `content` value into `NEXT_PUBLIC_GSC_VERIFICATION`. Then submit `https://www.yourdomain.com/sitemap.xml`.
- **Google Maps**: office and factory maps embed from their addresses automatically. For exact pins, put your *Share → Copy link* URLs in *Google Maps URL* and *Factory Maps URL* (used for **Get Directions**).
- **Google Business Profile**: put the profile URL and the "Ask for reviews" link into SETTINGS. The site shows *See Our Google Reviews* / *Review Us on Google* buttons and never displays copied or fabricated reviews.

## 5. Campaign tracking

In **Admin → Campaigns**, create a campaign with UTM values and copy the generated tracking link into your ad or bio. Leads, WhatsApp clicks, calls and conversions (Confirmed/Completed leads) with that `utm_campaign` are counted automatically.

## 6. Security notes

- Customer data (LEADS, EVENTS) is only reachable with the secret, through authenticated admin routes. Anonymous GETs to Apps Script return public website content only.
- Uploaded files go to a private Drive folder. Only people you share the folder with can open them.
- The rate limiter is in memory, per server instance. On serverless hosting, also enable your host's WAF/rate limiting (e.g. Vercel Firewall) for `/api/lead` and `/api/contact`. Turnstile adds bot protection.
- Rotate `API_SECRET` / `ADMIN_SESSION_SECRET` if they are ever exposed. Changing the session secret signs everyone out.
